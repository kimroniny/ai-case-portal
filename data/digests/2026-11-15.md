## 今日精选：ChatGPT Wallet
聊天机器人早已会帮人比价，真正难的是把“选好了”变成一笔银行和卡组织都认的支付。11 月 13 日 10:00 ET，OpenAI 推出 ChatGPT Wallet，官方称这是首个让 Agent 付款却拿不到用户真实卡信息、且每笔都要安全校验的钱包。用法并不激进：用户一次性绑卡，dots 找到商品后，先核对总价和所用卡，再用 Face ID 或指纹授权；随后由美运、Mastercard 或 Visa 签发仅用于该笔交易的支付代币，扣款记在原卡上，积分和合格争议保护仍在。初期只对美国 18 岁以上、持有合格美国发卡的 ChatGPT Pro 用户开放。CNBC 采访中，公司表示起步阶段不对交易抽成，先和商家、网络把基础打好；同时承认不少网站的防火墙和风控仍会误拦 Agent。联合航空已表示要阻止 Agent 订票，亚马逊也不允许 Agent 在其平台下单。对观察站而言，这比再记下一轮模型融资更值得看：个人 Agent 第一次被接进现有支付轨道，而不是另起一套钱包。下一看它何时开始对交易抽成、有多少商家真正放行，以及拒绝 Agent 下单会不会成为主流。
